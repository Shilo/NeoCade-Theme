# Contrast Audit

**Date:** 2026-05-07
**Method:** Design-token WCAG 2.1 contrast evidence, carried from Phase 3.4 /
`DESIGN_TOKENS.md`, plus live theme architecture check that every direction
uses the approved `base_color` / `accent_color` values.

| Direction | Base | Accent | Accent on base | Result |
|---|---|---|---:|---|
| Pulse | `#151A2E` | `#8BFF6A` | 13.62:1 | PASS |
| Slate | `#111820` | `#8BD3FF` | 10.94:1 | PASS |
| Bubble | `#241326` | `#FFB3E6` | 10.74:1 | PASS |
| Daybreak | `#0B2420` | `#76F2D1` | 11.96:1 | PASS |
| Burst | `#20112E` | `#FFD166` | 12.33:1 | PASS |

All five exceed WCAG 2.1 AA body-text contrast and also exceed the 7:1 AAA
target for accent-on-base. Text-on-surface colors are generated by
`NeoCadeTheme._regenerate_theme()` through the approved `is_light` branch:

- dark bases use `#F7F8FB` / `#B9C1D0`
- light overrides use `#1B2230` / `#5A6478`
