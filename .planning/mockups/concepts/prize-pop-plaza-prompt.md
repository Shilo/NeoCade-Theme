# Prize Pop Plaza Concept Prompt

Create a wide 16:9 raster concept-design image for "Prize Pop Plaza", a polished Godot UI theme concept named NeoCade. This is not a game screenshot and not final UI; it is a mood, atmosphere, shape-language, and material reference for a reusable Godot Control theme.

Show a modern prize counter and crane-game plaza translated into abstract UI materials: transparent prize-case panels, candy-bright but mature accents, ticket/card reward states, coral, lemon, mint, aqua, and soft red highlights over a dark neutral arcade base. Include at least one UI-adjacent motif such as a large touch-friendly button bar, reward-progress panel, tabs, dialog frame, card-station controls, joystick/button cluster, slider surface, or menu chrome. Use Inter-like upright signage feeling through abstract blocks and clean proportions, but do not render legible text.

Emotional target: playful, colorful, optimistic, reward-focused, and accessible without becoming childish. Shape language should use rounded control pads, transparent bay frames, clear success states, chunky tap targets, and organized prize-wall density.

Strict exclusions: cyberpunk, synthwave, vaporwave, scanlines, glitch, neon-noir, dystopian grime, pixel art UI, glow halos, mascots, toy-store clutter, novelty fonts, childish stickers, legible fake text.

Concept image note: mood/atmosphere and shape-language reference, not a final UI preview.
