# Boardwalk Sunset Concept Prompt

Create a wide 16:9 raster concept-design image for "Boardwalk Sunset", the recommended baseline direction for NeoCade, a polished Godot UI theme concept. This is not a game screenshot and not final UI; it is a mood, atmosphere, shape-language, and material reference for a reusable Godot Control theme.

Show a vibrant arcade hall by day or early evening, inspired by warm Round1 / Dave & Buster's style public entertainment venues: warm dark pine and amber panel surfaces, coral ticket-stub accents, mint-teal counter accents, cream text surfaces, and friendly social spacing. Include at least one UI-adjacent motif such as a button bar, panel stack, dialog frame, tabs, list row, slider rail, or popup/menu chrome. Use Inter-like upright signage feeling through abstract blocks and clean proportions, but do not render legible text.

Emotional target: colorful, professional, approachable, fun, and accessible. Shape language should use compact Godot/editor-friendly panels, small-radius cards, clear focus rings, warm cabinet-material hints, and a balanced open layout rather than decorative hero composition.

Strict exclusions: cyberpunk, synthwave, vaporwave, scanlines, glitch, neon-noir, dystopian grime, pixel art UI, glow halos, purple-blue gradient dominance, beige-only palette, legible fake text, mascot branding.

Concept image note: mood/atmosphere and shape-language reference, not a final UI preview.
