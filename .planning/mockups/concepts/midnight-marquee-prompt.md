# Midnight Marquee Concept Prompt

Create a wide 16:9 raster concept-design image for "Midnight Marquee", a polished Godot UI theme concept named NeoCade. This is not a game screenshot and not final UI; it is a mood, atmosphere, shape-language, and material reference for a reusable Godot Control theme.

Show a modern arcade cabinet hall interpreted as abstract UI materials: deep navy panel surfaces, a warm amber marquee band, warm pink secondary accents, cyan-blue highlights, and rows of cabinet-inspired panel strips. Include at least one UI-adjacent motif such as a button bar, stacked dialog frame, tabs, slider rail, popup chrome, or control cluster. Use Inter-like upright signage feeling through abstract blocks and clean proportions, but do not render legible text.

Emotional target: energetic after-dark cabinet hall, still clean and welcoming, with enough warmth to avoid sci-fi coldness. Shape language should use crisp rectangular panels, small-radius cabinet bezels, narrow marquee strips, and tactile button clusters. Lighting should be controlled and material-based, not glow-heavy.

Strict exclusions: cyberpunk, synthwave, vaporwave, scanlines, glitch, neon-noir, dystopian grime, pixel art UI, glow halos, Tron grid, dark alley, legible fake text, mascot branding.

Concept image note: mood/atmosphere and shape-language reference, not a final UI preview.
