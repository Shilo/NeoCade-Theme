# Orbital Playdeck Concept Prompt

Create a wide 16:9 raster concept-design image for "Orbital Playdeck", a polished Godot UI theme concept named NeoCade. This is not a game screenshot and not final UI; it is a mood, atmosphere, shape-language, and material reference for a reusable Godot Control theme.

Show a friendly futuristic arcade lobby or spaceship-adjacent public play deck, inspired by real immersive entertainment venues rather than cyberpunk fiction: clean dark surfaces, bright teal, citrus, warm amber, and soft violet accent rhythm, projected play fields, modular challenge-room panels, rounded onboarding stations, and luminous but restrained equipment surfaces. Include at least one UI-adjacent motif such as a segmented button bar, panel stack, dialog frame, tabs, slider rail, popup chrome, or team-session control cluster. Strict exclusions: cyberpunk, synthwave, vaporwave, scanlines, glitch, neon-noir, dystopian grime, pixel art UI, glow halos, Tron grid, military cockpit, command terminal, dark spaceship horror, legible fake text.
