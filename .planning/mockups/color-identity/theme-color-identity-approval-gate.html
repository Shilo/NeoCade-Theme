This board tests whether Pulse, Daybreak, Slate, Burst, and Bubble can feel distinct out of the box without requiring Button variations or custom control variations. Every visible move below must map to normal Godot Theme slots.

Preset sources shows the recommended shipping defaults for each built-in style. Shared stress source pushes one color through all five strategies to prove the algorithms stay distinct and avoid red, rose, coral, and hot-pink danger territory.

Theme Algorithms

The mockup uses HSL as a lightweight stand-in for a future Godot implementation. The important rule is not the exact color space: each role has an identity anchor, a controlled pull toward source_color, its own saturation/tone target, and a red-family guardrail.

Dynamic Source Proposal

Each card shows the dynamic role palette generated from its active source_color: default Button, OptionButton/MenuButton, inputs, selected rows/tabs, range controls, dialogs, and danger all get roles without type variations.

Godot Slot Map

These are the implementation targets the mockup is allowed to use. If a visual move cannot be expressed through these Theme items, it does not belong in the default out-of-box contract.

Default action

Button.normal, Button.hover, Button.pressed, Button.disabled, plus font and icon colors. This is the biggest behavioral change.

Menus and popups

OptionButton.normal, MenuButton inherited Button slots, PopupMenu.panel, PopupMenu.hover, check/radio icon modulation.

Inputs

LineEdit.normal, LineEdit.focus, TextEdit.normal, SpinBox.normal, caret color, selection color, and field font color.

Navigation and rows

TabBar.tab_selected, TabBar.tab_hovered, ItemList.selected, Tree.selected, row hover, guide colors, and selected text colors.

Range and toggles

ProgressBar.fill, slider track and grabber items, scrollbar grabbers, CheckBox.checkbox_checked_color, CheckButton.button_checked_color.

Dialogs and raised mode

PopupPanel.panel, embedded Window borders, dialog content margins, and solid bottom offset colors. No shadows, textures, or gradient chrome.

Decision Gates Before Implementation

Supersede old palette lock

DESIGN_TOKENS.md currently says built-ins must not be recolored or rederived. Approval of this board means that lock must be replaced by authored role palettes per style.

Allow Bubble light islands

Bubble only hits the mobile-game reference if cream/sky panels are allowed inside a dark outer shell. Rejecting light islands means Bubble needs a different, less faithful identity.

Use source_color workflow

The normal color workflow should be style + source_color. This mockup intentionally tests only that model.

Default Button becomes colored

If ordinary Button stays base-derived, the root problem survives. Semantic variations remain useful extras, but identity must exist without them.
