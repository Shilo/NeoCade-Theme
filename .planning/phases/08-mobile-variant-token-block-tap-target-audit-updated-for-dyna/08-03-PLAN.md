<audit_formula_contract>
The tap-target audit is executable from this plan. Implement these helper primitives first, then use the per-row formulas below so `PASS` / `FAIL` / `LIMITED` / `N/A` is deterministic:

- `font_y(type, slot := "font_size")`: Theme font size for `type.slot`, falling back to `default_font_size`.
- `sb_x(type, slot)`: `content_margin_left + content_margin_right` from the named StyleBoxFlat slot, or 0 if the slot is absent.
- `sb_y(type, slot)`: `content_margin_top + content_margin_bottom` from the named StyleBoxFlat slot, or 0 if the slot is absent.
- `icon_w(type, slot)` / `icon_h(type, slot)`: Texture size of the named icon slot after load, or 0 if absent.
- `k(type, slot)`: Theme constant value for the named slot, or 0 if absent.
- Button-family baseline: `button_w(type) = max(tokens.buttonMin, font_y(type) + sb_x(type, "normal") + k(type, "h_separation") + max(icon_w(type, "icon"), icon_w(type, "arrow"), icon_w(type, "bg")))`; `button_h(type) = max(tokens.buttonMin, font_y(type) + sb_y(type, "normal"), icon_h(type, "bg"))`.
- Input baseline: `input_h(type, slot := "normal") = max(tokens.inputMin, font_y(type) + sb_y(type, slot))`.
- Row baseline: `row_h(type) = max(tokens.rowMin, font_y(type) + k(type, "v_separation") + k(type, "line_separation") + k(type, "inner_item_margin_top") + k(type, "inner_item_margin_bottom"))`.
- Tab baseline: `tab_h(type, slot := "tab_selected") = max(tokens.tabMin, font_y(type) + sb_y(type, slot))`.
- Handle baseline: `handle_min(type, axis) = max(48, k(type, "minimum_grab_thickness"), k(type, "separation"), icon_w/icon_h of grabber or touch-dragger for that axis)`.
