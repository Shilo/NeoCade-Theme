## Godot Log Gate

Every Godot import or script verification command in affected plans must:

1. Redirect stdout/stderr/all PowerShell streams to a log under `.planning/phases/05-core-controls-buttons-inputs-labels-panels-desktop/logs/`.
2. Fail on nonzero `$LASTEXITCODE`.
3. Fail when `Select-String -Pattern '^(ERROR|SCRIPT ERROR):'` matches the log.

## ResourceSaver Strip Gate

Plan 05-07's `_phase5_resource_saver.gd` must save each approved direction with `ResourceSaver.save()`, then immediately run a Phase-4-equivalent strip helper that removes `load_steps=N`, drops every `[sub_resource]` block, drops every non-script `[ext_resource]` block, drops all `theme_data/...` and generated per-Control entries, and preserves only script linkage plus the nine exported `NeoCadeTheme` properties. The helper must assert size `< 2048`, absence of `[sub_resource]` / `theme_data/`, and unchanged exported values before the final PowerShell gate runs.

## Phase Gate

- The Wave 0 verifier files exist.
- Every task has an automated command in its PLAN.md.
- Godot logs are scanned for `ERROR:` and `SCRIPT ERROR:` wherever Godot import/script verification runs.
