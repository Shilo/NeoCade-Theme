## Godot Log Gate

Every Godot import or script verification command in affected plans must:

1. Redirect stdout/stderr/all PowerShell streams to a log under `.planning/phases/05-core-controls-buttons-inputs-labels-panels-desktop/logs/`.
2. Fail on nonzero `$LASTEXITCODE`.
3. Fail when `Select-String -Pattern '^(ERROR|SCRIPT ERROR):'` matches the log.
