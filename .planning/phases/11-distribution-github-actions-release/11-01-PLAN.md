# Phase 11 Plan 01: Release Workflow

**Status:** Complete

## Goal

Create the v1 release workflow and update distribution-facing docs.

## Tasks

1. Add `.github/workflows/release.yml` with `workflow_dispatch`.
2. Compute next semver from `addons/neocade_theme/VERSION`.
3. Download pinned Godot 4.6.2 and export templates.
4. Run headless import and showcase-open CI gates.
5. Build Web showcase from the `Web` export preset.
6. Bump `VERSION`, rewrite addon changelog header, commit, tag, and push.
7. Build addon zip from the tag using `git archive`.
8. Upload/deploy GitHub Pages artifact.
9. Publish GitHub Release with addon zip and Web showcase zip.
10. Update README/CHANGELOG distribution notes.

## Verification

- Workflow YAML exists and contains required release steps.
- `VERSION` is valid MAJOR.MINOR.PATCH.
- Release artifacts are named per roadmap.
