  <action>
    Populate `## Candidate Directions` with exactly five peer directions per D-03 and D-03b.

    The five directions must cover broad personality space. Seed from D-06 if still useful, but replace or rebalance if the survey supports a better spread. Before adopting a D-06 archetype, confirm at least one commercial survey example supports that personality. If a seeded archetype lacks survey support, replace it with a survey-validated alternative and document the replacement reason in the verification log.

    Do not preselect a base direction per D-01b. Do not make any direction "the raised one", "the flat one", "the mobile one", or "the desktop one"; each direction must explain both flat and raised behavior and desktop/mobile suitability.

    For each direction, include all fields from `<interfaces>`. Each direction section must use the heading format `### {Name}NeoCadeTheme` so verification can extract exactly five candidate sections. Apply D-14 and D-15 naming rules: PascalCase subclass form ending in `NeoCadeTheme`, evocative direction name, no cyber/synthwave/noir-coded names, and Boardwalk Sunset absent. Apply D-16 by noting Inter Variable Roman and dynamic `NeoCadeTheme` export compatibility in the shared constraints or each direction rationale.

    Verify WCAG AA contrast arithmetically for each base/accent pair. The document format must use machine-readable lines inside each candidate section:
    - `Base color: #RRGGBB`
    - `Accent color: #RRGGBB`
    - `Contrast ratio: N.NN:1 - WCAG AA PASS`

    Use 4.5:1 as a deliberate stricter floor for base/accent pairing so the accent remains safe when used for normal text, icons, and focus affordances. If a base/accent pair fails 4.5:1, revise the accent before completing the task. Do not rely on a prose-only "WCAG AA" claim.
  </action>
  <verify>
    <automated>
      powershell -NoProfile -Command "& {
        $doc = Get-Content -Raw '.planning/research/THEME-DIRECTIONS.md'
        $candidate = [regex]::Match($doc, '(?s)## Candidate Directions(.*?)(?=^## )', 'Multiline').Groups[1].Value
        $classes = ([regex]::Matches($candidate, '\b[A-Z][A-Za-z0-9]+NeoCadeTheme\b')).Value | Sort-Object -Unique
        if ($classes.Count -ne 5) { throw \"Expected 5 unique NeoCadeTheme subclass names in Candidate Directions, found $($classes.Count): $($classes -join ', ')\" }
        foreach ($bad in 'Cyber','Synth','Noir','Synthwave','NeonNoir','BoardwalkSunset') {
          if ($classes -match $bad) { throw \"Forbidden subclass naming term found: $bad\" }
        }
        foreach ($needle in 'Base color','Accent color','Contrast ratio','WCAG AA PASS','Personality','Target use case','Flat-mode behavior','Raised-mode behavior','Mobile-sizing notes','D-03','D-03b','D-06','D-14','D-15','D-16') {
          if ($candidate -notmatch [regex]::Escape($needle)) { throw \"Missing direction marker: $needle\" }
        }
        function Lum($hex) {
          $h = $hex.TrimStart('#')
          $vals = 0,2,4 | ForEach-Object { [Convert]::ToInt32($h.Substring($_,2),16) / 255 }
          $lin = $vals | ForEach-Object { if ($_ -le 0.03928) { $_ / 12.92 } else { [Math]::Pow((($_ + 0.055) / 1.055), 2.4) } }
          return 0.2126 * $lin[0] + 0.7152 * $lin[1] + 0.0722 * $lin[2]
        }
        $sections = [regex]::Matches($candidate, '(?ms)^###\s+.*?NeoCadeTheme.*?(?=^###\s+|\z)')
        if ($sections.Count -ne 5) { throw \"Expected 5 candidate sections, found $($sections.Count)\" }
        foreach ($s in $sections) {
          $base = [regex]::Match($s.Value, 'Base color:\s*(#[0-9A-Fa-f]{6})').Groups[1].Value
          $accent = [regex]::Match($s.Value, 'Accent color:\s*(#[0-9A-Fa-f]{6})').Groups[1].Value
          if (-not $base -or -not $accent) { throw 'Missing base/accent hex in candidate section' }
          $l1 = Lum $base
          $l2 = Lum $accent
          $ratio = ([Math]::Max($l1,$l2) + 0.05) / ([Math]::Min($l1,$l2) + 0.05)
          if ($ratio -lt 4.5) { throw \"WCAG AA contrast below 4.5:1 for $base / $accent = $([Math]::Round($ratio,2)):1\" }
          if ($s.Value -notmatch 'Contrast ratio:\s*\d+(\.\d+)?:1\s*-\s*WCAG AA PASS') { throw 'Missing numeric WCAG PASS line' }
        }
      }"
    </automated>
  </verify>
  <done>Exactly five peer candidate directions exist with names, palettes, contrast notes, behaviors, use cases, and rationale.</done>
